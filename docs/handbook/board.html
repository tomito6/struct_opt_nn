      How to use this board

      The board is a map of the repository, laid out like a Miro board: numbered frames (read them in order), cards inside them, and arrows between cards. Click any card for its explanation, the files behind it (with a button that opens VS Code at the line) and everything it connects to. New here? Press Tour.
